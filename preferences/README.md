# Preference tracking

This directory stores paper-review preferences that future Google Scholar digests should use.

## Files
- `interested_topics.md`: topics and paper patterns worth prioritizing
- `not_interested_topics.md`: topics and paper patterns worth deprioritizing
- `review_protocol.md`: the default workflow for later runs

## Comment protocol
After reviewing a paper file or PR, leave comments using one of these prefixes:
- `interested:` followed by why
- `not_interested:` followed by why
- `deeper_dive:` followed by what you want next
- `expand_topic:` followed by the topic to search next
